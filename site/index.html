Find, explain and fix flaky GitHub Actions pipelines

An agentic command line tool for Linux. Point it at a GitHub user or organisation: it scans the workflow runs, scores how flaky each job is, explains the likely cause with evidence and fixes it through a draft pull request, verified by rerunning the fix branch.

Status: pre-alpha. Setup, scanning, agent investigations, the chat, confirmed reruns and dispatches, fixes as draft pull requests and unattended runs from a systemd timer work. See the roadmap.

What flakipype does for you

Finds flaky jobs

Reads your workflow runs and ranks jobs that failed and then passed on rerun or on the same commit, with error signatures that group alike failures.

Explains them with evidence

An agent reads logs, commits and files, cites what it found, and a reviewer checks the verdict against that evidence before you see it.

Fixes through pull requests

The fixer proposes a small diff, opens it as a draft pull request and reruns CI on the fix branch to check that it holds.

Chat or timer

Work in a rich terminal chat with slash commands, or let flakipype run scan and fix from a systemd user timer.

Safe by design

flakipype reruns pipelines and writes code in your repositories. These rules are built in, not settings.

  • The default branch is never written. Every fix is a branch plus a draft pull request; merging stays with you.
  • A gate in code decides. Every tool has a fixed risk level; in ask mode you confirm every rerun, dispatch and push.
  • Logs are data, not instructions. Job logs, workflow files and source code cannot tell the agent what to do.
  • Nothing leaves unmasked. Secrets are masked before anything reaches the model.
  • Budgets are hard limits. Reruns, pull requests, tokens and time per run are capped.

Get started

Requires Linux (x86_64 or aarch64, glibc) with curl, tar and git. The script installs uv if you have none, checked against its published SHA-256. 

curl -fsSLO https://raw.githubusercontent.com/besessener/flakipype/v0.1.0/install.sh
sh install.sh
  1. Set up. flakipype setup asks for the model endpoint, downloads and verifies gh if needed and logs in to GitHub.
  2. Scan. flakipype scan finds and ranks the flaky jobs of your user or organisation.
  3. Fix. Run flakipype for the chat: investigate a finding, then /fix it and confirm the draft pull request.

The getting started tutorial walks you through it step by step.
